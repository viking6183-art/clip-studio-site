Clip Studio

A desktop app that turns long videos into short, subtitled vertical clips and posts them to the user's own TikTok, YouTube and Instagram accounts on a schedule.

How it works

  1. The user picks videos they own or have the rights to use.
  2. Clip Studio runs on the user's computer, finds the strongest moments, cuts vertical clips and adds subtitles, a title and hashtags.
  3. The user connects their own accounts with each platform's official login. Clips are then uploaded to those accounts at scheduled times, using the privacy setting the user chose.

TikTok integration

  • Login Kit: the user signs in to TikTok in their browser and approves access. The access token is saved only on the user's computer.
  • user.info.basic: shows which TikTok account is connected.
  • Content Posting API (video.publish): uploads a finished clip from the user's computer to their own account, with the caption and privacy level the user chose.

Clip Studio has no server. It never collects data about other TikTok users. See the Privacy Policy.
